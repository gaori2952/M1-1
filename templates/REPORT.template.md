# 공대생 콘텐츠는 언제 반응을 얻을까?

인스타그램 계정 성과 분석 · $common_start ~ $common_end · **일별 $common_days개 데이터**

> **핵심 결과:** 후반으로 갈수록 조회수가 커졌고, 9월 급증 이후에는 평소 성과도 높아졌다. 다만 10월 상승 주간에는 조회수에 비해 팔로우가 적게 늘었다.

## 1. 분석 목적과 질문

직접 운영하는 공대생 대상 계정의 데이터를 분석해, 앞으로 어떤 성과를 보고 콘텐츠 운영을 판단할지 정리했다.

1. 처음보다 조회수가 늘었는가?
2. 9월의 높은 성과는 며칠 반짝한 결과였는가?
3. 조회수가 많은 시기에는 팔로우도 그만큼 늘었는가?

## 2. 알아야 할 결과 3가지

### ① 후반 28일의 조회수는 처음 28일의 3.32배였다

| 비교 기간 | 하루 평균 조회수 |
| --- | ---: |
| 처음 28일: 5/29~6/25 | 23,419회 |
| 마지막 28일: 9/16~10/13 | 77,839회 |

**관찰:** 하루 평균 조회수가 **${views_last_first}배**로 늘었다. 다만 상위 5일이 전체 조회수의 **${views_top5_pct}%**를 차지했다.

**해석:** 콘텐츠가 더 많이 소비된 것은 분명하다. 매일 고르게 성장한 형태보다는 특정 시기에 반응이 집중된 형태다.

**판단할 점:** 최고 조회수만 보지 말고, 최근 7일 평균도 함께 보면서 관심이 이어지는지 확인한다.

### ② 9월 급증 이후에는 평소 성과도 높아졌다

급증한 9/23~24는 빼고, 직전 14일과 직후 14일을 비교했다.

| 하루 성과의 중앙값* | 직전: 9/9~22 | 직후: 9/25~10/8 |
| --- | ---: | ---: |
| 조회수 | 10,671.5회 | 54,898.5회 |
| 팔로우 | 88.5건 | 153건 |

\* 중앙값은 날짜별 값을 크기순으로 정렬했을 때의 가운데 값이다. 일부 매우 높은 날의 영향을 덜 받는다.

**관찰:** 조회수 중앙값이 **${persistent_views_median_ratio}배**로 높아졌다. 직후 14일 중 **13일**은 직전 조회수 중앙값을 넘었다.

**해석:** 급증 이틀만 잘된 것이 아니다. 그 뒤 2주에도 전반적으로 더 높은 관심과 팔로우가 기록됐다.

**판단할 점:** 반응이 좋았던 주제에 후속 콘텐츠를 붙여볼 근거가 있다. 다만 어느 게시물이 이 변화를 만들었는지는 별도로 확인해야 한다.

### ③ 10월에는 조회수에 비해 팔로우 확보가 약했다

큰 상승이 있었던 두 시기를 각각 7일씩 비교했다.

| 지표 | 9/23~29 | 10/6~12 |
| --- | ---: | ---: |
| 조회수 합계 | 980,844회 | 730,264회 |
| 팔로우 합계 | 3,912건 | 1,208건 |
| 조회수 1,000회당 팔로우 | ${surge_ratio_sep}건 | ${surge_ratio_oct}건 |

**관찰:** 10월 비교 주간의 조회수는 9월의 **74.5%**였지만, 팔로우는 **30.9%**였다. 조회수 1,000회당 팔로우는 **${surge_follow_drop}% 낮아졌다.** 비교 기간을 하루씩 앞뒤로 옮겨도 같은 방향이었다.

**해석:** 많은 조회수를 얻는 것과 팔로우를 확보하는 것은 다른 성과다. 10월에는 조회 규모에 비해 팔로우가 적게 기록됐다.

**판단할 점:** 팔로우 확대가 목표라면, 다음 콘텐츠에서 ‘후속 편 예고’를 넣어볼 만하다. 비슷한 주제·형식끼리 비교하면서 팔로우 총량과 조회수당 팔로우를 함께 본다. 이는 다음에 검증할 제안이다.

**비율 읽는 법:** `조회수 1,000회당 팔로우 = 같은 기간 팔로우 합계 ÷ 조회수 합계 × 1,000`. 같은 사람의 조회와 팔로우를 연결한 실제 전환율은 아니다. 팔로우 건수도 언팔로우를 차감한 순증가가 아니다.

## 3. 게시물 주제와 학기 일정은 어떻게 볼까?

실제 게시물에서 **9/24 ‘추석 공학수학’**, **10/7 ‘중간고사 대비 열역학’**을 확인했다. 시기에 맞춘 학습 콘텐츠를 운영했다는 근거다.

**해석 가설:** 방학·개강·시험 준비에 따라 필요한 자료가 달라져 반응에도 영향을 주었을 수 있다. 다만 9/1~11 조회수 일평균은 4,012회로 8월의 18,364회보다 낮았다. 따라서 ‘개강해서 잘됐다’고만 설명하기보다는 게시물 주제와 실제 반응 시점을 함께 봐야 한다.

## 4. 데이터와 분석 방법

| 항목 | 내용 |
| --- | --- |
| 출처·수집 | 사용자가 Instagram 분석 화면에서 내보낸 CSV 6개. [원본](data/raw) · [수집·이용 안내](DATA_SOURCE.md) |
| 전체 기간 | $overall_start ~ $overall_end, $overall_days일 |
| 분석 기간 | $common_start ~ $common_end, **$common_days일** — 최소 100시점 충족 |
| 컬럼 | 각 원본의 `Date`(날짜), `Primary`(값)를 결합해 조회수·시청자·상호작용·방문·팔로우·링크 클릭 구성 |
| 결측치 | 10/14 팔로우만 없어 지표 비교에서 그날을 제외. 0으로 채우지 않음 |
| 중복·이상치 | 중복 날짜 없음. `Q3 + 1.5 × IQR`을 넘는 높은 값을 표시하되 실제 성과일 수 있어 삭제하지 않음 |

분석에는 다음 방법을 사용했다.

- **7일 이동평균:** 당일과 이전 6일의 평균으로 일별 변동을 줄여 추세를 확인했다. 완전한 7일이 없는 첫 6일은 계산하지 않았다.
- **구간별 평균·중앙값:** 길이가 같은 28일·14일·7일 구간끼리 비교했다. 중앙값으로 소수의 급등일에만 의존하는 결과인지 확인했다.
- **비율·변화율:** 구간 합계로 조회수당 팔로우를 계산하고, `(나중 값 ÷ 이전 값 − 1) × 100`으로 차이를 표시했다. 분모가 0이면 계산하지 않았다.

추세는 시간에 따른 전체 흐름, 계절성은 주기적으로 반복되는 패턴, 노이즈는 그 밖의 변동이다. 이번에는 추세와 일별 변동을 살폈으며, 약 4.5개월 자료만으로 학기마다 같은 패턴이 반복된다고 판단하지 않았다.

## 5. 결론과 한계

**조회수 확대는 확인됐다. 다음에는 ‘팔로우도 함께 늘었는가’를 별도로 평가해야 한다.** 운영할 때 조회수의 7일 평균, 팔로우 총량, 조회수 1,000회당 팔로우를 함께 기록하면 된다.

이 결과를 판단할 때 기억할 한계는 세 가지다.

- **원인:** 계정 전체의 일별 데이터다. 게시물별 효과·광고·학사 일정의 영향을 분리하지 못했다.
- **기간:** 한 계정의 짧은 기간이며 비교 구간은 그래프를 본 뒤 선정했다. 다른 시기에도 같은 결과가 나오는지는 추가 확인이 필요하다.
- **지표:** 팔로우는 순증가가 아니고, 조회수당 팔로우는 개인별 전환율이 아니다. 원본에 시간대·광고 포함 설정은 기록되지 않았다.

## 6. AI 사용 로그

| 사용 작업 | 사용 이유 | 검증 방법 |
| --- | --- | --- |
| 전처리·계산 코드 작성 | 날짜 결합과 반복 계산 자동화 | 원본 CSV와 정제값 대조, 결측·0·날짜 처리 등 테스트 10개 통과 |
| 그래프·통계 작성 | 기간별 차이를 쉽게 비교 | 원본에서 주요 수치 독립 재계산, 그래프 축·기간·표시 확인 |
| 해석·리포트 정리 | 핵심 결과를 추리고 문장 단순화 | 관찰과 가설 구분, 급등일 제외·비교 기간 변경으로 결과 방향 확인 |

AI가 작성한 해석 중 게시물 주제와 학사 일정의 영향은 가설이다. 최종 운영 판단은 위 수치와 실제 게시 이력을 함께 보고 내린다.

## 7. 재현 방법과 출처

Python 3.10 이상에서 저장소를 내려받아 실행한다. [상세 실행 안내](README.md) · [라이브러리 버전](requirements.txt) · [검증 기록](VALIDATION.md)

```bash
python -m pip install -r requirements.txt
python analysis.py
```

[analysis.py](analysis.py)는 원본에서 통계·그래프·리포트를 다시 만든다. [정제 데이터와 상세 통계](data/processed)에 전체 계산 결과를 보관했다. 본문에는 핵심 그래프 3개를 골랐으며, 다른 분석 그림은 [images](images)에 있다.

데이터와 게시물 캡처는 계정 소유자가 제공·공개 승인한 자료다. 제3자의 자유로운 재사용을 허용하는 공개 라이선스는 별도로 부여하지 않았다. [출처·수집 방법·이용 범위](DATA_SOURCE.md)
