# 공대생 콘텐츠는 언제 반응을 얻을까?

### 게시물 주제와 학기 흐름으로 읽는 인스타그램 트렌드

직접 운영하는 공대생 대상 인스타그램 계정의 성과를 분석했다. 조회수가 높아진 날에는 방문과 팔로우도 늘었는지, 반응이 급증한 뒤에도 관심이 이어졌는지를 살펴본다. 게시물 주제와 방학·개강·시험 준비 시기가 겹쳤을 가능성도 함께 해석한다.

## 무엇을 발견했나

- **조회수와 행동은 같은 날 함께 움직였다.** 조회수–방문 상관계수는 0.886, 조회수–팔로우는 0.748이었다.
- **9월 급증 이후에도 평균 수준이 높았다.** 급증한 이틀을 제외한 직후 14일의 조회수 일평균은 직전 대비 2.63배, 팔로우는 1.82배였다.
- **콘텐츠의 주제와 시기도 함께 봐야 한다.** 방학·개강·시험 준비 시기에는 학습 자료의 필요가 달라질 수 있다. 다만 숫자의 동반 변화만으로 그 영향을 확정할 수는 없다.

자세한 수치와 출처, 관찰과 가설의 구분은 [REPORT.md](REPORT.md)에 정리했다.

## 실행하기

Python **3.10 이상**에서 저장소를 복제한 뒤 실행한다. 분석에 필요한 원본 데이터가 포함되어 있다.

```bash
git clone https://github.com/gaori2952/M1-1.git
cd M1-1
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python analysis.py
```

Windows PowerShell에서는 `py -3 -m venv .venv`로 가상환경을 만들고 `.venv/Scripts/Activate.ps1`로 활성화한다.

실행하면 정제 데이터, 통계표, 분석 그래프 4개와 `REPORT.md`가 생성된다. 리포트 문장을 고칠 때는 [템플릿](templates/REPORT.template.md)을 수정한다.

```bash
python -m unittest discover -s tests -v
```

검증 환경은 Python 3.12.14다. 직접 의존성은 [requirements.txt](requirements.txt), 검증한 환경의 전체 버전은 [requirements-lock.txt](requirements-lock.txt)에 기록했다.
