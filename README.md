# M1-1 — Instagram Trend Analysis

### 게시물 주제와 학기 흐름으로 읽는 인스타그램 트렌드

직접 운영하는 공대생 대상 인스타그램 계정의 성과를 분석했다. 조회수가 높아진 날에는 방문과 팔로우도 늘었는지, 반응이 급증한 뒤에도 관심이 이어졌는지를 살펴본다. 게시물 주제와 방학·개강·시험 준비 시기가 겹쳤을 가능성도 함께 해석한다.

## 무엇을 발견했나

- **9월 급증 뒤에는 평소 성과도 높아졌다.** 급증 이틀을 제외한 전후 14일의 조회수 중앙값이 5.14배로 올랐고, 직후 14일 중 13일이 직전 중앙값을 넘었다.
- **10월에는 조회수에 비해 팔로우 확보가 약했다.** 9/23~29와 10/6~12를 비교하면 조회수 1,000회당 팔로우는 3.99 → 1.65로 58.5% 낮아졌다. 비교 창을 하루씩 옮겨도 방향은 같았다.
- **다음 과제는 관심을 다음 콘텐츠로 연결하는 것이다.** 팔로우 확대를 목표로, 비슷한 주제에서 후속 편 예고와 과목별 안내를 순서대로 실험한다. 학사 일정은 기획 맥락으로 활용하고 성과는 실제 반응 시점으로 판단한다.

자세한 수치와 출처, 관찰과 가설의 구분은 [REPORT.md](REPORT.md)에 정리했다.

원본 139일은 그대로 보존했다. 팔로우의 마지막 하루가 없어 지표 간 비교는 10월 13일까지의 138일로 맞췄다. 결측을 0으로 채우거나 높은 성과를 임의로 삭제하지 않았다.

## 실행하기

Python **3.10 이상**에서 저장소를 복제한 뒤 실행한다. 분석에 필요한 원본 데이터가 포함되어 있다.

```bash
git clone https://github.com/gaori2952/M1-1.git
cd M1-1
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python analysis.py
```

Windows PowerShell에서는 `py -3 -m venv .venv`로 가상환경을 만들고 `.venv/Scripts/Activate.ps1`로 활성화한다.

실행하면 정제 데이터, 통계표, 분석 그래프 6개와 `REPORT.md`가 생성된다. 리포트 문장을 고칠 때는 [템플릿](templates/REPORT.template.md)을 수정한다.

```bash
python -m unittest discover -s tests -v
```

검증 환경은 Python 3.12.14다. 직접 의존성은 [requirements.txt](requirements.txt), 검증한 환경의 전체 버전은 [requirements-lock.txt](requirements-lock.txt)에 기록했다.
