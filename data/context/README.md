# 게시물 사례 기록

확인일: 2026-10-15. 운영자가 자신의 게시물을 캡처해 분석에 포함하도록 요청했다. 계정 단위 시계열의 변화를 해석하기 위한 사례 2개이며, 전체 게시물을 분류하거나 학사 일정 효과를 검증한 데이터셋이 아니다.

게시일은 화면의 날짜와 연결된 `time` 요소에서 확인했다. 게시물 날짜 요소의 UTC 시각은 각각 `2026-09-24T11:16:10.000Z`, `2026-10-07T11:11:05.000Z`였다. 두 게시물은 한국 시간으로도 같은 날짜다. 원본 성과 CSV의 집계 시간대는 확인되지 않았으므로 서로 다른 화면의 시간을 임의로 같은 기준으로 환산해 일별 기여도를 계산하지 않았다.

캡처는 Instagram에서 실제 렌더링된 화면의 표지만 직사각형으로 지정해 저장했다. 내용 합성·재작성은 하지 않았으며 댓글 작성자, 메시지 알림, 관리 화면은 포함하지 않았다. 브라우저 화면의 슬라이드 이동 버튼은 남아 있다. 원문 링크와 이 기록으로 캡처의 맥락을 확인할 수 있다.

학교별 개강·방학·중간고사 일정은 수집하지 않았다. 해당 학사 일정이 변화를 설명할 수 있다는 주장은 운영자의 가설로 출처를 구분한다. 게시물별 누적 성과도 일별 계정 성과의 직접 원인이나 같은 날의 수치로 사용하지 않는다.
